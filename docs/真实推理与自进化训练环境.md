# OpenDriveVLA 真实推理与自进化训练环境

## 1. 推荐结论

本机为 RTX 4060 Laptop GPU（8 GB 显存）。该配置适合运行 Windows Demo、LiteVLA
训练与评估，但不建议直接运行 OpenDriveVLA 的 UniAD 视觉塔和完整端到端推理；即使
0.5B 语言骨干较小，定制 MMCV/MMDet3D CUDA 算子、多相机特征和中间张量仍会占用大量显存。

| 任务 | 推荐环境 | 建议硬件 |
|---|---|---|
| Demo / LiteVLA 自进化 | Windows 10/11，Python 3.10 | CPU 即可，8 GB 内存以上 |
| OpenDriveVLA 官方推理 | Ubuntu 22.04 或 WSL2 Ubuntu 22.04，CUDA 11.8，Python 3.10 | 实践上建议 24 GB 显存起步 |
| LoRA Reflection SFT / DPO | 原生 Ubuntu 22.04 优先，WSL2 可用于试跑 | 建议 A100 40/80 GB；24 GB 需缩短序列并使用量化/梯度检查点 |
| 完整视觉端到端训练 | 多 GPU Linux 服务器 | 多张 A100/H100，64 GB 以上内存和高速 SSD |

显存数字是针对本项目依赖结构的工程建议，不是 OpenDriveVLA 官方公布的最低配置。

## 2. Windows 上安装 WSL2

以管理员身份打开 PowerShell：

```powershell
wsl --install -d Ubuntu-22.04
wsl --update
wsl -l -v
```

重启后安装最新 NVIDIA Windows 驱动。WSL2 中不要再次安装 Linux 显卡驱动，只安装
CUDA Toolkit。官方入口：

- WSL 安装：https://learn.microsoft.com/windows/wsl/install
- NVIDIA CUDA on WSL：https://docs.nvidia.com/cuda/wsl-user-guide/index.html
- NVIDIA 驱动：https://www.nvidia.com/Download/index.aspx

建议将项目复制到 WSL 的 Linux 文件系统（例如 `~/AutoDriving-VLA-Self-evolving`），
不要长期在 `/mnt/e/` 下编译 MMCV，以避免 NTFS 挂载带来的编译和 I/O 性能损失。

## 3. 创建 Python/CUDA 环境

进入 Ubuntu：

```bash
sudo apt update
sudo apt install -y git build-essential ninja-build libgl1 libglib2.0-0 libgfortran5
conda create -n drivevla python=3.10 -y
conda activate drivevla
python -m pip install --upgrade pip setuptools wheel
```

安装与官方仓库一致的 PyTorch 2.1.2 + CUDA 11.8：

```bash
pip install torch==2.1.2 torchvision==0.16.2 torchaudio==2.1.2 \
  --index-url https://download.pytorch.org/whl/cu118
```

然后在本项目根目录分阶段安装。DeepSpeed 必须在 Torch 之后安装：

```bash
DS_BUILD_OPS=0 pip install --no-build-isolation -r requirements-deepspeed.txt
pip install -r requirements-gpu.txt
```

PyTorch 历史版本命令：https://pytorch.org/get-started/previous-versions/

## 4. 安装 OpenDriveVLA 官方定制依赖

官方代码：https://github.com/DriveVLA/OpenDriveVLA

```bash
git clone https://github.com/DriveVLA/OpenDriveVLA.git \
  references/models/VLA-code/OpenDriveVLA-code
cd references/models/VLA-code/OpenDriveVLA-code

export CUDA_HOME=/usr/local/cuda-11.8

cd third_party/mmcv_1_7_2
pip install -r requirements/optional.txt
MMCV_WITH_OPS=1 pip install -v .

cd ../mmdetection3d_1_0_0rc6
pip install scipy==1.10.1 scikit-image==0.19.3 fsspec
pip install -v .

pip install mmdet==2.26.0 mmsegmentation==0.29.1 \
  mmengine==0.9.0 motmetrics==1.4.0 casadi==3.6.0
```

官方安装说明：https://github.com/DriveVLA/OpenDriveVLA/blob/main/docs/1_INSTALL.md

验证环境：

```bash
nvidia-smi
nvcc --version
python -c "import torch; print(torch.__version__, torch.cuda.is_available(), torch.cuda.get_device_name())"
python -c "import mmcv, mmdet3d, deepspeed, transformers; print('environment ok')"
```

## 5. 准备真实推理数据

完整官方推理不是只放入 mini JSONL。需要 nuScenes v1.0 trainval/full、CAN bus、Map
Expansion v1.3、UniAD temporal infos、`cached_nuscenes_info.pkl` 和评估 GT。

官方数据说明：https://github.com/DriveVLA/OpenDriveVLA/blob/main/docs/2_DATA_PREP.md

基座权重放在 `references/models/OpenDriveVLA-0.5B/`。模型页面需要登录并接受共享联系
信息的访问条件：https://huggingface.co/OpenDriveVLA/OpenDriveVLA-0.5B

## 6. 运行实际推理

在官方代码根目录执行：

```bash
conda activate drivevla
bash scripts/eval_drivevla.sh /absolute/path/to/OpenDriveVLA-0.5B 1
```

这是官方公布的推理/评估入口：
https://github.com/DriveVLA/OpenDriveVLA/blob/main/docs/3_EVAL.md

若要将官方输出接入 Windows Demo，使用保留的导入器：

```powershell
python scripts/import_opendrivevla_outputs.py `
  --plan-conv path/to/plan_conv.json `
  --scenario-manifest path/to/scenario_manifest.jsonl
```

## 7. 自进化训练的两条路线

轻量自进化在现有 Windows 环境即可运行：

```powershell
python scripts/train.py
python scripts/evaluate.py
```

OpenDriveVLA LoRA 路线应在 Linux/CUDA 环境先检查资产，再依次运行：

```bash
python scripts/train_opendrivevla_peft.py --stage sft --check-only
python scripts/train_opendrivevla_peft.py --stage reflection_sft --check-only
python scripts/train_opendrivevla_peft.py --stage dpo --check-only

python scripts/train_opendrivevla_peft.py --stage sft
python scripts/train_opendrivevla_peft.py --stage reflection_sft
python scripts/train_opendrivevla_peft.py --stage dpo
```

三个阶段需要本机已有的 `data/opendrivevla_training/sft.jsonl`、
`reflection_sft.jsonl` 和 `dpo.jsonl`。当前入口冻结视觉塔并对语言模型注意力层执行 LoRA，
属于轨迹/Reflection 监督训练；它尚未把六相机像素重新送入视觉塔，因此不能称为完整视觉
端到端自进化。若要完成后者，需要沿用官方数据管线加载六相机与 UniAD 特征，并把
Reflection/DPO 目标接入官方 multimodal batch。OpenDriveVLA 官方 README 当前仍把训练脚本
列为待发布项，因此完整复现应以官方后续训练代码为准。

## 8. 本机最现实的方案

1. 本机 Windows 继续运行 Demo 与 LiteVLA 自进化。
2. 在 WSL2 中完成依赖编译和 `--check-only` 校验。
3. 正式推理租用或使用一张 24 GB 以上 GPU；若仍显存不足，换 A100 40/80 GB。
4. Reflection SFT/DPO 建议直接使用 A100 40/80 GB，训练结果导回本项目 Demo。
